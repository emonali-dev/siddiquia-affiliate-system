# Siddiquia Technology — Affiliate & Referral System

GitHub Pages-ready responsive front-end prototype.

## Upload to GitHub
1. Download and extract this ZIP.
2. Upload **all files and folders inside** to the root of your GitHub repository (keep `index.html` at root).
3. GitHub → Repository **Settings → Pages**.
4. Choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.

## Important limitation
This is a visual/front-end prototype only. It has sample data and temporary browser interactions. It is **not** a production affiliate platform. It does not provide secure accounts, persistent database, genuine referral attribution, commission approvals, or payouts. Do not enter real customer or payment data.

## Required production backend
Recommended: Next.js/React + Node.js API + PostgreSQL, secure session authentication and role-based permissions. Implement server-side referral tracking, lead attribution, project/invoice/payment records, commission ledger, payout approvals, fraud checks, audit logs and backups.

## Commission rule
20% of the full agreed project value, with commission payable proportionally as each client installment is actually received. Do not deduct company development or operating costs. Example: $2,000 received on a $5,000 project → $400 commission payable. Refunds, chargebacks and disputes must be handled by a written policy.
